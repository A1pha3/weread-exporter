## 🔧 核心概念速查

在深入学习之前，您需要了解以下核心概念：

### 书籍 ID（Book ID）

**定义**：微信读书中每本书籍的唯一标识符

**格式**：32 字符的哈希字符串

**获取方式**：

```bash
# 从 URL 中提取
https://weread.qq.com/web/bookDetail/08232ac0720befa90825d88
#                      ↑ 这是书籍 ID
#                      08232ac0720befa90825d88

# 使用命令行获取
weread-exporter -b 12345_67890 --list-ids
```

### 书单 ID（Booklist ID）

**定义**：微信读书书单的唯一标识符

**格式**：包含下划线的字符串，如 `12345_67890`

**特点**：

| 类型 | ID 格式 | 示例 |
|-----|--------|------|
| 单本书籍 | 32 字符哈希 | `08232ac0720befa90825d88` |
| 书单 | `数字_数字` | `12345_67890` |

### Canvas Hook 技术

**为什么需要它**：微信读书使用 Canvas 渲染文本内容以防止复制

**解决方案**：通过 JavaScript 注入拦截 Canvas 的绘制过程

**优势**：

- 获取原始渲染内容，而非解析后的 HTML
- 保留完整的样式信息（字体、颜色、大小）
- 支持复杂排版的准确识别

### 导出格式

| 格式 | 适用场景 | 依赖工具 | 平台限制 |
|-----|---------|---------|---------|
| EPUB | 通用电子书格式，支持多数阅读器 | ebooklib | 无 |
| PDF | 打印或桌面阅读 | weasyprint | 无 |
| MOBI | Kindle 设备专用 | kindlegen | 仅 Linux |
| TXT | 纯文本，最佳兼容性 | 无 | 无 |
| Markdown | 编辑和版本控制 | 无 | 无 |
