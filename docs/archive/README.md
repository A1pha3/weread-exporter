# 文档归档

## 概述

本目录用于存放已废弃或过时的文档，以保持项目文档的清晰和最新状态。

## 归档原则

1. **过时文档**: 当文档内容与当前代码不符且无法更新时
2. **废弃功能**: 当某个功能被完全移除时，其相关文档应归档
3. **重大变更**: 当文档结构发生重大变化时，旧版本可归档

## 归档文档列表

目前没有归档文档。所有文档均为最新版本。

## 使用说明

1. 归档文档仅供参考，不应作为当前功能的依据
2. 如需查看最新文档，请参阅根目录下的文档
3. 归档文档可能包含过时的API或配置信息

## 管理规范

- 归档文档应保持原始格式和内容
- 添加归档日期和原因说明
- 定期审查归档文档，考虑完全删除过时内容
